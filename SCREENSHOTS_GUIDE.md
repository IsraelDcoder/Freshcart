## How to Take Screenshots

### Windows
```
Method 1: Print Screen → Paste in Paint → Save
Method 2: Win+Shift+S → Snipping Tool
Method 3: Use screenshot software (Snagit, Greenshot, etc.)
```

### macOS
```
Cmd+Shift+4 → Select area → Saves to Desktop
Or: Cmd+Shift+3 → Full screen
```

### Linux
```
Print Screen → Save
Or: gnome-screenshot
```

---

## Screenshot Quality Guidelines

✅ **DO:**
- Use clear, readable fonts
- Capture full page content
- Show meaningful data
- Include all UI elements
- Use consistent window size
- Name files clearly (e.g., `01_landing_page.png`)

❌ **DON'T:**
- Include personal/sensitive data
- Show incomplete pages
- Capture at odd angles
- Use blurry screenshots
- Mix different resolutions
- Include cursor artifacts

## Video Demonstration Guide

### Video Structure (2-3 minutes)

**Part 1: Introduction (30 seconds)**
- Show application name
- Brief overview
- System requirements

**Part 2: Features Demo (90 seconds)**
- Navigate login page
- Create account
- Browse products
- Add to cart
- Complete checkout
- View order history

**Part 3: Highlights (30 seconds)**
- Key features summary
- Technical highlights
- Close application

### Recording Tips

1. **Use Screen Recording Software:**
   - Windows: Built-in Xbox Game Bar (Win+G)
   - macOS: QuickTime Player
   - Linux: SimpleScreenRecorder or OBS
   - Cross-platform: OBS Studio (Free)

2. **Video Quality:**
   - Resolution: 1280×720 (720p) or 1920×1080 (1080p)
   - Frame rate: 30 fps minimum
   - Audio: Clear narration or silent

3. **Preparation:**
   - Test application first
   - Have test data ready
   - Create test account beforehand
   - Plan the flow
   - Dress professionally for audio

4. **Recording:**
   - Speak clearly and slowly
   - Show each feature clearly
   - Click deliberately (not too fast)
   - Explain what you're doing
   - Keep pace steady

5. **Editing (Optional):**
   - Add intro/outro slides
   - Include captions
   - Add transitions
   - Cut dead time
   - Export as MP4
